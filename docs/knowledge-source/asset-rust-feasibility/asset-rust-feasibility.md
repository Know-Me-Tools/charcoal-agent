# ASSET Rust Windows DLL feasibility

The ASSET Rust Windows DLL feasibility paper is a delivered research document that investigates a Rust core and Windows DLL compatibility. The portfolio lists it as research edition 1.0 dated 25 October 2026. It says Rust is technically plausible and that nothing has been demonstrated.[^pf3]

## ASSET Rust Windows DLL feasibility status and version

No repository was identified for this entry, so no version or release can be given. The portfolio's status line reads: "Research edition 1.0, dated 25 October 2026. Rust is technically plausible; a drop-in DLL, Windows build, host integration or performance improvement has not been demonstrated."[^pf3]

## What is stated about the ASSET Rust feasibility paper

- It compares a direct procedural ABI, a thin compatibility shell and incremental migration.[^pf3]
- It covers ownership, unwinding, callbacks, UI threading, parity, deployment and bounded go or no-go evidence.[^pf3]
- The current binary interface, reference behavior, licensing and deployment constraints need evidence before implementation decisions.[^pf3]
- It is distinct from the interface stub specification and does not authorize a full rewrite.[^pf3]
