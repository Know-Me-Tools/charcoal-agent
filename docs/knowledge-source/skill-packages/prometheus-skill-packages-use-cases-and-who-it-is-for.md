# Prometheus skill packages use cases and who they are for

## Who the Prometheus skill packages are for

Developers who use AI coding assistants and want the work to follow a plan that survives between sessions: a written specification, clear file ownership, and a record of what was checked.[^full-readme] Mini suits developers on Windows, or anyone who wants the process without a native toolchain.[^mini-readme]

## Planning and building a feature with the Prometheus skill packages

Ask `kbd-process-orchestrator` to plan a small feature. It records the specification, the production entry point, acceptance criteria and file ownership, and the complete change is built before its integration check runs.[^full-readme][^mini-readme]

## Other documented Prometheus skill workflows

`iterative-evolver` runs an improvement cycle. `deep-research` runs a sourced investigation. `prometheus-ui-ux` handles interface and product-copy work while keeping the project's own design rules in charge.[^full-readme][^mini-readme]

## Coordinating several agents with the Prometheus skill packages

`agent-team-creator`, `agent-team-manage` and `agent-team-handoff` create a team, track its tasks and claims, and record when ownership passes from one role to another. Where a coding assistant cannot delegate, the skills say the work runs one step at a time instead.[^full-readme][^mini-readme]

## Prometheus Skills Mini inside The Boss

On a machine that already has the full pack, Mini's README says to use Mini only inside The Boss application's own data directory.[^mini-readme]
