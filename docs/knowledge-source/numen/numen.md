# Numen execution fabric status and what is stated

Numen is a proposed fabric for governed orchestration and portable execution across interchangeable hosts, including human and agent identity credentials. The portfolio lists it as an architecture proposal. A complete operating fabric is not established, so Numen is not available.[^portfolio]

## Numen status and version

The portfolio status for Numen is "Architecture proposal with a newly published Enclave deployment standard; a complete operating fabric is not established."[^portfolio] No repository was identified for this entry, so there is no version number to quote.

## What Numen is stated to do

- Numen is proposed to govern work and let it run on any of several interchangeable hosts.[^portfolio]
- Its identity design covers credentials for both humans and agents.[^portfolio]
- That identity design is "additive proposal content, not current UAR scope or implemented fabric."[^portfolio]
- The portfolio lists a current identity edition (21 October), an original historical edition and a new Enclave deployment standard (24 October).[^portfolio]
- Status of the identity edition: the portfolio labels it current, but the edition's own header calls it a Revision 2 candidate that is not published. Both are true as written. The portfolio's label governs here, so read "current" as the latest working edition, not a published release.[^portfolio]

## How Numen relates to other products

The portfolio says Numen Enclave adds a proposed deployment boundary for owner-controlled private work.[^portfolio] It says the Candle-VLLM fork is part of the intended inference infrastructure.[^portfolio] It says Tranquil's private agent-job design is covered by the Numen identity edition.[^portfolio] The portfolio treats such relationships as architectural intent, not proof of completed integration.
