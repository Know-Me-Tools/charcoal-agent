# Landscape

Scope: neutral, sourced notes on other tools and standards, written as capability and trade-off descriptions. Every claim about another product carries that maker's public URL and a retrieval date; "not stated" marks what the pages read did not say. Claims about KnowMe AI, LLC and Prometheus AGS products repeat only what their own knowledge-base pages state, and KnowMe is described as design intent because it is not released.
