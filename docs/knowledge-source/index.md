# KnowMe AI, LLC Knowledge Bundle

Source documents for the KnowMe site knowledge base. Each product directory holds one concept per file. Files are built into `content/knowledge/` by the build step described in the authoring guide.

## Products

* [KnowMe](knowme/) - The KnowMe product: what it is, platforms and status, features, privacy.
* [Universal Agent Runtime](universal-agent-runtime/) - The agent runtime behind KnowMe chat.
* [Surreal Memory Server](surreal-memory-server/) - The knowledge-graph memory server.
* [BossFang](bossfang/) - The BossFang product.
* [The Boss](the-boss/) - The Boss product.
* [Skill Packages](skill-packages/) - Installable skill packages for agents.
* [Phase Exit](phase-exit/) - Evidence-based completion decisions against an adopted contract.
* [KnowMe Project Management](knowme-project-management/) - The project setup and conversion skill.
* [HTMX Doc Forge](htmx-doc-forge/) - Document tools for branded publications.
* [Native agent creator](native-agent-creator/) - Rust templates and scaffolding for native agents.
* [Artifact Refiner](artifact-refiner/) - Document refinement and teaching workflows.
* [Prometheus](prometheus/) - Who makes each product, its licence and where to get it, as short direct answers.
