# Locus (Private Dot) status and what is stated

Locus, also called Private Dot, is a proposed owner-controlled private assistant and operator-coach. The portfolio lists it as a design proposal. Bounded foundation work exists, but it is not an implemented Locus runtime, so Locus is not available to use.[^portfolio]

## Locus status and version

The portfolio status for Locus is "Design proposal; bounded foundation work is not an implemented Locus runtime."[^portfolio] Its repository is Know-Me-Tools/locus. Version line: {{v:locus}}.

## What Locus is stated to do

- Locus is proposed to have durable state, selective memory and replaceable execution workers.[^portfolio]
- The repository README calls itself the documentation-first home for Locus and says the checkout does not contain an implemented Locus runtime.[^locus-readme]
- It holds the Book of Locus specification, a design kit, a captured mindmap, and an opt-in local capture wrapper with tests.[^locus-readme]
- The edition status note counts 287 mapped requirement IDs and calls them "specification mappings, not passing implementation tests."[^locus-status]
- Book rendering, the full PDF and Book publication to IPFS are unfinished, and the canonical Book including later amendments is unpublished.[^locus-readme][^portfolio]

## How Locus relates to other products

The portfolio says Prometheus Pulse is a capability mapped into Locus and its project-learning workflow.[^portfolio] It describes Companion as a potential shared workspace for dot, Locus and other agent systems.[^portfolio] It says full App/Locus integration with the KnowMe Concierge is not established.[^portfolio] The portfolio treats such relationships as architectural intent, not proof of completed integration.
