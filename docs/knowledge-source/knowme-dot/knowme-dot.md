# KnowMe dot operator service status and what is stated

The KnowMe dot operator service is a proposed persistent shared control plane with a canonical per-user memory and task-scoped retrieval for replaceable workers. The portfolio lists it as a specification and synthetic prototype, with no live service certified. It is not a service you can use today.[^portfolio]

## KnowMe dot status and version

The portfolio status for KnowMe dot is "Specification and synthetic prototype; no live service certified."[^portfolio] No repository was identified for this entry, so there is no version number to quote.

## What KnowMe dot is stated to do

- KnowMe dot is proposed as a persistent shared control plane for replaceable workers.[^portfolio]
- It is proposed to hold one canonical memory per user and to give workers retrieval limited to the task at hand.[^portfolio]
- The portfolio lists a full technical operator paper (version 3, 19 October) and a condensed synthetic architecture preview.[^portfolio]
- Per-user brain additions remain unpublished. The preview behaviour is synthetic and "does not certify service capabilities."[^portfolio]

## How KnowMe dot relates to other products

The portfolio describes Companion as a potential shared workspace for dot, Locus and other agent systems.[^portfolio] The portfolio treats such relationships as architectural intent, not proof of completed integration.
