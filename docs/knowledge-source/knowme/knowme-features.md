# KnowMe features

KnowMe is designed around eight tiles: Chat, Hands, Ask Image, Audio Scribe, Prompt Lab, Skills, Models and Settings. KnowMe has not been publicly released, so none of these is available to the public today. This page describes what each tile is designed to do and where KnowMe AI, LLC's development stands.

## The eight tiles of KnowMe

- **Chat**: conversation with streaming replies, optional visible reasoning, and tools and skills that can be turned on per message.
- **Hands**: autonomous agents that run on a schedule for the person, each limited by a policy that says which skills it may use.
- **Ask Image**: questions about images, scans, screenshots and PDFs, designed to run vision models locally.
- **Audio Scribe**: transcription designed to run on the device.
- **Prompt Lab**: a place to try and refine prompts.
- **Skills** and **Models**: manage what the assistants can do and which models they use, local or remote.
- **Settings**: policies, devices and sync.

## What exists in KnowMe today

In KnowMe AI, LLC's development builds of KnowMe, chat and the local memory graph work on desktop and mobile. Hands, multi-device sync and the plugin system are still being built, and the remaining tiles are designed but not yet built. None of this is publicly available yet, and KnowMe AI, LLC has not announced a release date.

## What you can use today instead of waiting for KnowMe

You can talk with the KnowMe agent on this site; the site runs on the Universal Agent Runtime, the same agent runtime KnowMe is built on. You can also download The Boss, KnowMe AI, LLC's free, open-source desktop workspace for macOS and Windows, which packages the Universal Agent Runtime and BossFang.
