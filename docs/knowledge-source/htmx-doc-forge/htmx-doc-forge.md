# HTMX Doc Forge

HTMX Doc Forge, also listed as Build Branded Documents, is a set of document tools for portable branded publications, SVG explanations, responsive viewers and IPFS publishing workflows that keep receipts.[^portfolio] The portfolio lists it as existing document tools.[^portfolio]

## HTMX Doc Forge status and version

HTMX Doc Forge has {{v:docforge}}. The portfolio's status line for HTMX Doc Forge reads: "Existing document tools; current portfolio uses HTMX 2.0.8 explicitly."[^portfolio] The source repository of HTMX Doc Forge is not public, and no release is stated.

## What is stated about HTMX Doc Forge

- HTMX Doc Forge produces portable branded publications.[^portfolio]
- HTMX Doc Forge covers SVG explanations and responsive viewers for documents.[^portfolio]
- HTMX Doc Forge includes publishing workflows to IPFS, the content-addressed file network, that produce receipts.[^portfolio]
- The current portfolio edition states that it uses HTMX 2.0.8.[^portfolio]

## What the portfolio does not establish for HTMX Doc Forge

The portfolio notes that local skill and document tooling exist, but a public-safe standalone product export has no verified IPFS receipt.[^portfolio] There is no standalone public page for HTMX Doc Forge in the portfolio.

## How HTMX Doc Forge relates to other products

The portfolio groups Doc Forge with Prometheus Skills, Know Decision, Phase Exit and Project Management as tools that support building and governing the work. It says these relationships are architectural intent, not proof of completed integration.[^portfolio]
