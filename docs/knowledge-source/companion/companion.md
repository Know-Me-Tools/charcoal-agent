# Companion (provisional working name) status and what is stated

Companion is a provisional working name for a potential shared coordination workspace for dot, Locus and other agent systems. The portfolio records a tested local Axum and Postgres MVP. The broader product remains proposed, and Companion is not available.[^portfolio]

## Companion status and version

The portfolio status for Companion, paraphrased on the cloud point, is: "Tested local Axum/Postgres MVP with task hierarchy, events, deduplication, SSE replay and five MCP tools. Prototype screenshots exist. Cloud deployment is not verified."[^portfolio] No repository was identified for this entry, so there is no version number to quote.

## What Companion is proposed to do

- Companion is proposed to show progress centrally, surface approvals and blockers, track deliverable receipts and coordinate work across agents.[^portfolio]
- The tested MVP runs locally.[^portfolio]

## What remains ahead for Companion

- No live cross-agent integration, recurring reporting pipeline or public standalone publication is verified.[^portfolio]
- The portfolio says "local MVP tests do not establish cloud readiness."[^portfolio]
- The working name is provisional.[^portfolio]

## How Companion relates to other products

The portfolio describes Companion as a potential workspace for dot, Locus and other agent systems, and says no live cross-agent integration is verified.[^portfolio] The portfolio treats such relationships as architectural intent, not proof of completed integration.
