# Review record: web search toggle, privacy wording and the Web source label

- **Piece:** `content/site/web-search.ts` -> `WEB_SEARCH_CONTENT`.
- **Strings:** toggle label "Search the web"; tooltip and accessible description "Off by default. When on, the words of your question are sent to a third-party search service, and web sources are marked Web."; screen-reader state text "On" and "Off"; source badge "Web"; in-reply marker title "Web source from {host}".
- **Why:** OD-7 of the `site-web-search` change. The visitor chooses web search per question or session; consent is given at the point of use, and the wording must say what happens to the question.
- **Claims checked against the system:** the question text is sent to Firecrawl, a third-party search API, only while the toggle is on (the site proxy maps `web_search: true` to a second pinned agent; the search wrapper calls Firecrawl `POST /v2/search`; evidence: `.kbd-orchestrator/phases/site-chat-hardening-and-polish/evidence/13-local-web-search-proof/RESULTS.md`); web sources carry the "Web" label and the host in the Sources block and the About panel. "Off by default" matches the preference store (default off) and the build flag. No pricing, no compliance claim, no claim about what the third party does with the text.
- **Not covered:** a legal review of sending visitor-derived queries to a third party (recommended by the design; not arranged). The wording says the words of the question are sent to a third-party search service and does not name Firecrawl.
- **Voice:** short, concrete, no hype, no exclamation marks.
