# Give your coding assistant a repeatable process (Solutions)

A visitor asks: "My coding assistant does different things every session. How do I get it to plan, build and review the same way?" Two released skill packages and several supporting tools address this. Status tags on this page: [shipped] means the facts file records a published release or package. [planned] means source without a release, a prototype, a specification or a design, and is never described here as available.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-25.

## Repeatable process: the skill packages [shipped] (Solutions)

The Prometheus Skill Pack, release v1.13.0, is the broad distribution. It covers many languages and domains, process orchestration and learning, and optional native services. Prometheus Skills Mini, release v1.12.1, is a smaller portable set with Node entry points. Both share skill names and the KBD workflow, the packages' name for the assess, plan, execute, reflect cycle. They share skill names, so they should not share a home directory.

## Repeatable process: supporting tools (Solutions)

- KnowMe Project Management [planned, source only]: sets up or converts a project with shared agent instructions, a spec-driven change workflow, an agent team and a documentation site.
- Phase Exit [planned, preview]: returns one of six verdicts on whether a stage is complete, from receipts checked against an adopted contract.
- Prometheus Knowledge [planned, source only]: stop hooks write a queue record, and a separate learning worker publishes immutable knowledge snapshots.
