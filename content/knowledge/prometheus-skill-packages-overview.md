# Prometheus skill packages overview

## What the Prometheus skill packages are

A skill is a packaged set of instructions an AI coding assistant can load for a kind of task. The Prometheus skill packages give a coding assistant a repeatable way to plan work, assign ownership, implement a specification and keep useful lessons for later sessions. There are two packages: the full Prometheus Skill Pack and Prometheus Skills Mini.

Source: Prometheus Skill Pack README, retrieved 2026-10-13.

## The full Prometheus Skill Pack (Skill Packages)

The full pack is broad. It covers many languages and domains, process orchestration and learning, and it can add optional native services for durable memory, model routing, research and signed execution records. It installs with Git, Node and Bash; some workflows also need Python, jq or Rust.

Source: Prometheus Skill Pack README, retrieved 2026-10-13.
Source: Prometheus Skill Pack guide, introduction, retrieved 2026-10-13.

## Prometheus Skills Mini (Skill Packages)

Mini is a smaller, portable set: process, team, research and UI guidance with Node entry points. It needs Node 22 or later and Git, and runs on Windows, macOS and Linux without Git Bash, Python or WSL. The Boss website describes Mini as a development process an agent can follow: assess, plan, execute, reflect, with OpenSpec holding the specifications.

Source: Prometheus Skills Mini README, retrieved 2026-10-13.
Source: The Boss website, retrieved 2026-10-13.

## What the Prometheus skill packages share

Both packages share skill names, the KBD workflow and contracts, but they are separate products. A copied skill or an exported team definition does not prove that a given coding assistant can run it. Both work without the separate Prometheus Companion extension.
