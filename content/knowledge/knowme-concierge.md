# KnowMe Concierge status and what is stated

KnowMe Concierge is the KnowMe web and desktop client for the KnowMe agent, and its code is the concierge that answers on this site. The portfolio lists it as an existing implementation, so something does exist and runs here. Full integration with the KnowMe App, Locus and an authentic voice is not established, and the sources announce no separate release.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.
Source: KnowMe Concierge repository README, retrieved 2026-10-24.

## KnowMe Concierge status and version

The portfolio status for KnowMe Concierge is "Existing implementation; full App/Locus and authentic-voice integration not established." Its repository is the Know-Me-Tools repository cited below. Version line: no tagged release (last commit 2026-10-24).

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## What KnowMe Concierge is stated to do

- KnowMe Concierge is the web and desktop client for the KnowMe agent.
- It streams the agent's replies, keeps your threads locally, and syncs KnowMe's built-in skills to your runtime.
- The README lists React 19, Vite, Tailwind CSS 4, PGlite in the browser for local threads, and Tauri 2 for the desktop app.

Source: KnowMe Concierge repository README, retrieved 2026-10-24.

## How KnowMe Concierge relates to other products

The README says the agent runs inside the Universal Agent Runtime, a separate Rust service, and that this client connects to it. The portfolio says integration with the KnowMe App, Locus and an authentic voice is not established. The portfolio treats such relationships as architectural intent, not proof of completed integration.
