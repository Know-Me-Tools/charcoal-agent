## How many skills the Prometheus skill packages have

Counted by listing the skill folders in the repository on 2026-10-13. The full pack, version 1.12.2 in its `skill-system.json` on that date, has 120 skills in its `skills/<category>/<skill>/` folders, each with a SKILL.md; two of them are imported from other repositories. With nested helper skills it has 404 SKILL.md files in total, not counting installed dependencies. Mini, version 1.12.1 in its `package.json`, has 100 skills in its `skills/<name>/` folders.

Source: Prometheus Skill Pack skill-system manifest, retrieved 2026-10-13.
Source: Prometheus Skills Mini package manifest, retrieved 2026-10-13.

## Status of the full pack in the Prometheus skill packages

The latest GitHub release of the full pack is v1.13.0 (2026-10-18), and the latest release of Mini is v1.12.1 (2026-10-12). The skill counts on this page were taken from version 1.12.2 and have not been recounted for v1.13.0. The full pack's `skill-system.json` gave release version 1.12.2 when it was last read for this page; treat a version in a manifest as the source version, not a tested release. Its README does not select a release. Support depends on the release, the host machine and the entry point, and a successful install does not prove that every requested service works.

## Status of Mini in the Prometheus skill packages

Mini's `package.json` gives version 1.12.1; treat that as the source version, not a tested release. Mini's source and documentation were published for review on 2026-10-05. The note says this is a source publication, not a release. The owner plans to resume testing once the code base has stabilised. Its source targets Windows, macOS and Linux with Node 22 or later; acceptance on real installed coding assistants is still pending on each of the three.
