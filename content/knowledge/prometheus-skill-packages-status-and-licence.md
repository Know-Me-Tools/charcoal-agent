# Prometheus skill packages status and licence

## How many skills each Prometheus skill package has (Skill Packages)

See each package's own skill index. The full pack's catalog is `SKILLS.md` and its inventory is generated from `skill-system.json`; the counts in its files do not all agree, so this knowledge base does not quote one. Mini's counts and targets come from its `skill-system.json`, `package.json` and `versions.toml`.

Source: Prometheus Skill Pack skill catalog, retrieved 2026-10-12.
Source: Prometheus Skill Pack README, retrieved 2026-10-12.
Source: Prometheus Skills Mini README, retrieved 2026-10-12.

## Full Prometheus Skill Pack status (Skill Packages)

Its README does not select a release. Support depends on the release, the host machine and the entry point, and a successful install does not prove that every requested service works.

Source: Prometheus Skill Pack README, retrieved 2026-10-12.

## Prometheus Skills Mini status (Skill Packages)

Mini's source and documentation were published for review on 2026-10-05. The note says this is a source publication, not a release, and that an earlier release integration did not pass as a whole. Its source targets Windows, macOS and Linux with Node 22 or later; acceptance on real installed coding assistants is still pending on each of the three.

Source: Prometheus Skills Mini source publication note, 2026-10-05, retrieved 2026-10-12.
Source: Prometheus Skills Mini maintenance and platform limits, retrieved 2026-10-12.

## Prometheus skill packages licences

The full pack is MIT licensed and has a LICENSE file. Mini is MIT licensed according to its package manifest and README; its repository does not yet contain a LICENSE file. Skills imported into either package keep their own licences.
