# HTMX Doc Forge

HTMX Doc Forge, also listed as Build Branded Documents, is a set of document tools for portable branded publications, SVG explanations, responsive viewers and IPFS publishing workflows that keep receipts. The portfolio lists it as existing document tools.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## HTMX Doc Forge status and version

HTMX Doc Forge has no tagged release (last commit 2026-10-13). The portfolio's status line for HTMX Doc Forge reads: "Existing document tools; current portfolio uses HTMX 2.0.8 explicitly." The source repository of HTMX Doc Forge is not public, and no release is stated.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## What is stated about HTMX Doc Forge

- HTMX Doc Forge produces portable branded publications.
- HTMX Doc Forge covers SVG explanations and responsive viewers for documents.
- HTMX Doc Forge includes publishing workflows to IPFS, the content-addressed file network, that produce receipts.
- The current portfolio edition states that it uses HTMX 2.0.8.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## What the portfolio does not establish for HTMX Doc Forge

The portfolio notes that local skill and document tooling exist, but a public-safe standalone product export has no verified IPFS receipt. There is no standalone public page for HTMX Doc Forge in the portfolio.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## How HTMX Doc Forge relates to other products

The portfolio groups Doc Forge with Prometheus Skills, Know Decision, Phase Exit and Project Management as tools that support building and governing the work. It says these relationships are architectural intent, not proof of completed integration.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.
