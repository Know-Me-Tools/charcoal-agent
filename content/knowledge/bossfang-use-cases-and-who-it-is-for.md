# BossFang use cases and who it is for

## Who BossFang is for

Developers and technical users who want to run and manage a set of AI agents on their own machine, with tools, memory and messaging channels, from a dashboard and a command line. BossFang is for those who also want SurrealDB storage, Surreal Memory and access to models through the Universal Agent Runtime instead of upstream's defaults.

Source: BossFang AGENTS.md, product identity and fork additions, retrieved 2026-10-13.

## Running agents locally with BossFang

The documented use is the one inherited from LibreFang: a local agent operating system that runs agents backed by language models and manages their tools, memory, channels and networking.

Source: BossFang AGENTS.md, product identity and fork additions, retrieved 2026-10-13.

## Using BossFang with the Universal Agent Runtime

BossFang can send agent runs to a Universal Agent Runtime instance, including one that The Boss manages, so model access and policy stay in the runtime.

Source: BossFang connects to UAR, retrieved 2026-10-13.

## BossFang design intent

Design intent, not a finished capability: the ledger tracks channel routing and authorized observer copies across hosts as work in progress. The connection to the Universal Agent Runtime is implemented in source but not yet built and tested.
