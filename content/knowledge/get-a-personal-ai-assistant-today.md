# Get a personal AI assistant you can install today (Solutions)

A visitor asks: "I just want an AI assistant I can install now. What can I get?" One KnowMe AI, LLC product has a download: The Boss. KnowMe itself has no release. [planned] means source without a release, a prototype, a specification or a design, and is never described here as available.

## Install an assistant today: The Boss [shipped] (Solutions)

The Boss is a free, open-source AI desktop workspace for macOS and Windows. The latest release is v2.2.41. Download it from https://the-boss.know-me.tools; no account is required. You can hold conversations with cloud or local model providers, run agent sessions with MCP tools, skills and approval boundaries, and work with knowledge, documents and code. Provider access needs your own credentials. The portfolio notes that current-source features are not automatically in released installers.

## Install an assistant today: what comes in the installer (Solutions)

The v2.2.41 release notes say the installers include complete pinned Universal Agent Runtime sidecar payloads for macOS Apple Silicon, macOS Intel and Windows x64. The integration manifest on the main branch also lists BossFang, but the release notes do not name it, and the portfolio notes that current-source features are not automatically in released installers. This page does not establish that BossFang is in the installer. The Surreal Memory Server is not in the installer. The Boss works with it over MCP as a separate service.
