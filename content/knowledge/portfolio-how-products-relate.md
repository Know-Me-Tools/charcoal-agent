## How do the KnowMe AI, LLC products relate to each other? (KnowMe and Prometheus portfolio)

The portfolio says its relationships are architectural intent, not proof of completed integration. The relationships the sources state most clearly are these.

- The Boss is built on the open-source Cherry Studio client.
- The Boss installers bundle the Universal Agent Runtime and BossFang as programs that run beside it.
- The KnowMe client README says the KnowMe agent runs inside the Universal Agent Runtime and the client connects to it.
- The Boss works with the Surreal Memory Server over MCP as a separate service. The server is not in the installer.

Most other products have no stated relationship. See the stated relationships page for the full list.
