# Knowledge Gateway

Knowledge Gateway gives federated access to knowledge across document sources, through shared adapters and MCP tools. MCP is the Model Context Protocol, the open standard agents use to call tools. The portfolio's status is "Existing project with phased capabilities; graph-discovery completeness unverified."

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## Knowledge Gateway status and version

No repository was identified for Knowledge Gateway, so no version exists to quote. The project is described as existing, with capabilities arriving in phases. The portfolio has not verified that graph discovery is complete. Treat any claim that Knowledge Gateway finds everything across a graph of documents as unverified.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## What Knowledge Gateway states

* It reaches several document sources through one set of shared adapters.
* It exposes that access as MCP tools.
* Its capabilities are phased. The portfolio does not list which phases exist.
* The portfolio found no standalone public HTML publication receipt for it.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.
