# KnowMe AI, LLC

KnowMe AI, LLC is the company behind know-me.tools and the products described on this site. The chat on this site is the KnowMe agent, an AI concierge that answers from KnowMe AI, LLC's own product documentation and shows where each answer came from. The KnowMe agent is an AI, not a person, and it is not the KnowMe app.

## Products from KnowMe AI, LLC

KnowMe AI, LLC makes the products described on this site:

- **KnowMe**, a personal AI platform that is still in development and has not been publicly released. See the KnowMe overview for what it is designed to do.
- **The Boss**, a free, open-source AI desktop workspace for macOS and Windows that you can download today from https://the-boss.know-me.tools.
- **IPFS Sync for Obsidian**, an early-preview Obsidian plugin and command-line tool that syncs a vault over IPFS through your own node.

## The parts KnowMe AI, LLC's products run on

KnowMe AI, LLC also builds the parts these products run on. The Universal Agent Runtime is a governed agent runtime, written in Rust, that routes models and runs agents and tools under policy; the KnowMe agent on this site runs on it, and The Boss packages it. BossFang is an agent operating system forked from the open-source LibreFang project, with SurrealDB storage, for agents that run on schedules; The Boss packages it too. The Surreal Memory Server is a memory service with a knowledge graph and search that The Boss works with as a separate service. Each will get its own page on this site.

## How the know-me.tools site and the KnowMe agent work

This site is led by the KnowMe agent, which runs on KnowMe AI, LLC's Universal Agent Runtime. You talk with the KnowMe agent in the chat window; it answers from a curated knowledge base about KnowMe AI, LLC's products and cites its sources. The KnowMe agent is read-only: it cannot create accounts, take payments or act on your behalf. Each conversation is kept as a thread in your browser, and your messages also go to the Universal Agent Runtime on the server and to a cloud language model that composes the reply; KnowMe privacy describes that flow. The KnowMe agent on this site is not the KnowMe app.
