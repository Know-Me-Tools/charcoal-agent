# KnowMe AI, LLC

KnowMe AI, LLC is the company behind know-me.tools and the products described on this site. The chat on this site is the KnowMe agent, an AI concierge that answers from KnowMe AI, LLC's own product documentation and shows where each answer came from. The KnowMe agent is an AI, not a person.

## Products from KnowMe AI, LLC

KnowMe AI, LLC makes the products described on this site:

- **KnowMe**, a personal AI platform that is still in development and has not been publicly released. See the KnowMe overview for what it is designed to do.
- **The Boss**, a free, open-source AI desktop workspace for macOS and Windows that you can download today from https://the-boss.know-me.tools.
- **IPFS Sync for Obsidian**, an early-preview Obsidian plugin and command-line tool that syncs a vault over IPFS through your own node.

KnowMe AI, LLC also builds the parts these products run on, including the Universal Agent Runtime, BossFang and the Surreal Memory Server. This site describes each product from its own documentation and says plainly what is available now and what is still being built.

## How the know-me.tools site and the KnowMe agent work

This site is led by the KnowMe agent, which runs on the Universal Agent Runtime. You talk with the KnowMe agent in the chat window; it answers from a curated knowledge base about KnowMe AI, LLC's products and cites its sources. The KnowMe agent is read-only: it cannot create accounts, take payments or act on your behalf. Each conversation becomes a thread stored in your own browser, on your device, so your history with the site stays with you.

## Buying from KnowMe AI, LLC

Nothing is sold on know-me.tools. The Boss is free to download and open source. Any paid offering from KnowMe AI, LLC will have its own site when it exists.
