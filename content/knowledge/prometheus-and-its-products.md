# Prometheus and its products

## What is Prometheus?

Prometheus is the name of Prometheus AGS's server-side AI platform work. Prometheus AGS makes the Universal Agent Runtime, the Surreal Memory Server, BossFang and the Prometheus skill packages. KnowMe AI, LLC makes KnowMe, The Boss and IPFS Sync for Obsidian, and builds KnowMe and The Boss on those Prometheus parts.

## Who makes the Universal Agent Runtime (Prometheus)?

Prometheus AGS makes the Universal Agent Runtime, a server written in Rust that runs AI agents and calls models and tools under policy. Its source is public at https://github.com/Prometheus-AGS/universal-agent-runtime. KnowMe AI, LLC builds KnowMe and The Boss on it, and the KnowMe agent on this site runs on it.

Source: Universal Agent Runtime repository, retrieved 2026-10-13.

## Who makes BossFang (Prometheus)?

Prometheus AGS makes BossFang, an agent operating system forked from the open-source LibreFang project, with SurrealDB storage, for agents that run on schedules. BossFang's source is at https://github.com/GQAdonis/librefang. The Boss, from KnowMe AI, LLC, bundles BossFang.

Source: BossFang repository, retrieved 2026-10-13.

## Who makes the Surreal Memory Server (Prometheus)?

Prometheus AGS makes the Surreal Memory Server, a memory service for AI agents with a knowledge graph and search, written in Rust on SurrealDB. Its source is public at https://github.com/Prometheus-AGS/surreal-memory-server. KnowMe and The Boss, from KnowMe AI, LLC, work with it through MCP (Model Context Protocol) as a separate service.

Source: Surreal Memory Server repository, retrieved 2026-10-13.

## Who makes the Prometheus skill packages?

Prometheus AGS makes both Prometheus skill packages: the full Prometheus Skill Pack at https://github.com/Prometheus-AGS/prometheus-skill-system and the smaller Prometheus Skills Mini at https://github.com/Prometheus-AGS/prometheus-skills-mini. Both are packages of skills for AI coding assistants.

Source: Prometheus Skill Pack repository, retrieved 2026-10-13.
Source: Prometheus Skills Mini repository, retrieved 2026-10-13.

Yes. The Universal Agent Runtime's code, including its SDKs, is MIT licensed, and its repository has a LICENSE file naming Prometheus AGS as copyright holder. Its documentation is licensed CC-BY-4.0. The MIT licence lets you use, change and redistribute the code if you keep the copyright and licence notice.

Source: Universal Agent Runtime LICENSE, retrieved 2026-10-13.
Source: Universal Agent Runtime README, retrieved 2026-10-13.

## Is the Surreal Memory Server MIT licensed? (Prometheus)

Yes. The Surreal Memory Server is MIT licensed (LICENSE file in the repository), with Prometheus AGS as copyright holder. The MIT licence lets you use, change and redistribute it if you keep the copyright and licence notice. Its source was published for review on 2026-10-05; that publication is not a release.

Source: Surreal Memory Server LICENSE, retrieved 2026-10-13.
Source: Surreal Memory Server source publication note, retrieved 2026-10-13.

## Are the Prometheus skill packages MIT licensed?

Yes, both are. The full Prometheus Skill Pack is MIT licensed (LICENSE file in the repository). Prometheus Skills Mini is MIT licensed (LICENSE file in the repository). Skills that either package imports from other projects keep their own licences.

Source: Prometheus Skill Pack LICENSE, retrieved 2026-10-13.
Source: Prometheus Skills Mini LICENSE, retrieved 2026-10-13.

## Is BossFang open source and what licence does it use? (Prometheus)

Yes. BossFang is open source under the MIT licence. Its LICENSE file names the LibreFang contributors as copyright holders, because BossFang is a fork of the open-source LibreFang project. Prometheus AGS makes BossFang; its source is at https://github.com/GQAdonis/librefang.

Source: BossFang LICENSE, retrieved 2026-10-13.

## Is The Boss open source and what licence does it use? (Prometheus)

Yes. The Boss, from KnowMe AI, LLC, is open source under the GNU Affero General Public License v3.0 (AGPL-3.0), and its repository has a LICENSE file. The Boss keeps that licence because it is built on the open-source Cherry Studio client. It is free to download from https://the-boss.know-me.tools.

Source: The Boss LICENSE, retrieved 2026-10-13.

## Who makes The Boss and KnowMe? (Prometheus)

KnowMe AI, LLC makes The Boss and KnowMe, and also IPFS Sync for Obsidian. The Boss and KnowMe are built on parts made by Prometheus AGS: the Universal Agent Runtime, BossFang and, through MCP, the Surreal Memory Server. The Boss is available now. KnowMe has not been publicly released; it is planned to be released under the MIT licence.
