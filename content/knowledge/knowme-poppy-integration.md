# KnowMe integration with Poppy status and what is stated (KnowMe Poppy integration)

The KnowMe integration with Poppy is a design for KnowMe support and recovery that uses the external Personal Agent Protocol. Poppy itself is not a KnowMe-owned product. The portfolio lists a published integration design and says implementation is not established.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.
