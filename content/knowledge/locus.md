# Locus (Private Dot) status and what is stated

Locus, also called Private Dot, is a proposed owner-controlled private assistant and operator-coach. The portfolio lists it as a design proposal. Bounded foundation work exists, but it is not an implemented Locus runtime, so Locus is not available to use.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## Locus status and version

The portfolio status for Locus is "Design proposal; bounded foundation work is not an implemented Locus runtime." Its repository is Know-Me-Tools/locus. Version line: no tagged release (last commit 2026-10-21).

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## What Locus is stated to do

- Locus is proposed to have durable state, selective memory and replaceable execution workers.
- The repository README calls itself the documentation-first home for Locus and says the checkout does not contain an implemented Locus runtime.
- It holds the Book of Locus specification, a design kit, a captured mindmap, and an opt-in local capture wrapper with tests.
- The edition status note counts 287 mapped requirement IDs and calls them "specification mappings, not passing implementation tests."
- Book rendering, the full PDF and Book publication to IPFS are unfinished, and the canonical Book including later amendments is unpublished.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## How Locus relates to other products

The portfolio says Prometheus Pulse is a capability mapped into Locus and its project-learning workflow. It describes Companion as a potential shared workspace for dot, Locus and other agent systems. It says full App/Locus integration with the KnowMe Concierge is not established. The portfolio treats such relationships as architectural intent, not proof of completed integration.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.
