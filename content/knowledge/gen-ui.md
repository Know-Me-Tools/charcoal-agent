# gen_ui, the cross-platform UI core (gen_ui / cross-platform UI core)

gen_ui is a partly implemented shared Rust application core with thin web, desktop and Flutter surfaces for KnowMe. The portfolio's status is "Implemented modules plus architectural specification; platform acceptance remains specific." Some modules exist. The whole is not stated to be complete on every platform.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## gen_ui status and version (gen_ui / cross-platform UI core)

No repository was identified for gen_ui, so no version exists to quote. "Platform acceptance remains specific" means acceptance is judged per platform. The portfolio does not claim that every surface has passed.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## What gen_ui states (gen_ui / cross-platform UI core)

* The design is one Rust core shared by every surface, with each surface kept thin.
* The surfaces named are web, desktop and Flutter.
* A published source record carries the gen_ui technical specification, which the portfolio checked as reachable on 21 October 2026.
* A local HTML copy, "gen_ui, Technical Specification and Architecture", has no verified public address.
