# Landscape and comparison questions

Short answers to the comparison questions visitors ask. Each answer rests on the sourced landscape pages in this knowledge base, which paraphrase other makers' own pages as of 2026-10-12. KnowMe is not released, so answers about KnowMe describe KnowMe AI, LLC's design intent.

## How is KnowMe different from OpenAI dots? (Landscape)

OpenAI dots are shipped always-on agents that run on OpenAI's cloud computers with OpenAI's model, reach the person through ChatGPT, Slack, Teams and voice, and keep their memories in OpenAI's systems, according to OpenAI's pages. KnowMe is not released; by design it runs on the person's own devices, keeps conversations and memory in an encrypted local database there, syncs only between the person's own devices and servers, and can use local models or several providers. Dots do more today; KnowMe asks the person to run more themselves. The page OpenAI dots and KnowMe gives the full comparison, with minuses on both sides.

Source: OpenAI, Introducing dots (2026-09-29), retrieved 2026-10-12.
Source: OpenAI Help Center, Getting started with your dot, retrieved 2026-10-12.

## Why not just use ChatGPT? (Landscape)

For many people ChatGPT is the right choice: it is available now with free sign-up, comes with OpenAI's models, and its desktop app brings ChatGPT and Codex to the desktop with context from files and screen content, according to OpenAI's download page. According to OpenAI's dots pages, a dot's memories are held in OpenAI's systems; the ChatGPT download page read for this knowledge base does not state memory or data handling. KnowMe is being designed for a different trade: data and memory on the person's own hardware and a free choice of models, at the cost of running more oneself and of waiting, because KnowMe is not released.

Source: OpenAI, ChatGPT download page, retrieved 2026-10-12.
Source: OpenAI Help Center, Getting started with your dot, retrieved 2026-10-12.

## Is The Boss better than Cherry Studio? (Landscape)

This knowledge base does not say so. The Boss is built on Cherry Studio under the same AGPL-3.0 licence; much of its chat experience is Cherry Studio's work. The Boss adds artifact authoring, context management, skills selection, the agent protocols A2A, AG-UI and A2UI, and a bundled Universal Agent Runtime and BossFang that it administers. It lacks Cherry Studio's Linux build. Choose Cherry Studio for Linux or upstream releases; choose The Boss for the bundled, governed agent runtime on macOS or Windows.

## Do I need a cloud account to use these products? (Landscape)

For The Boss, no: it is free, open source and downloadable without an account, though using a cloud model provider inside it needs that provider's credentials. KnowMe is designed without a central account, but it is not released. The Universal Agent Runtime and the Surreal Memory Server are self-hosted software you run yourself. Among other tools, Jan states that no account is needed.

## Is KnowMe an always-on agent like dots or Gemini Spark? (Landscape)

No. Always-on agents run on their maker's servers while the person's device is off. KnowMe is designed to run on the person's own devices, with scheduled agents (Hands) that are designed but not yet built; anything that ran while the person's hardware was off would have to run on a server the person operates. If always-on behaviour is your first need, see Always-on personal agents compared with KnowMe for the vendors that offer it today.

## Which of these tools can I use today? (Landscape)

From KnowMe AI, LLC, The Boss for macOS and Windows. From Prometheus AGS, the Universal Agent Runtime at version 1.0.0 with public source and an MIT licence, BossFang as public source without an established end-user release, and the Surreal Memory Server as source published for review rather than a tested release. KnowMe has no public release and no announced date. Every other product named in the landscape pages is available from its own maker under that maker's terms.
