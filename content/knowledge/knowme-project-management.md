# KnowMe Project Management

KnowMe Project Management is a repeatable way to set up a new project, or convert an existing one, for code, business processes, research and documentation. The portfolio lists it as an existing project-setup skill and documentation.

Source: KnowMe and Prometheus portfolio, Edition 2, retrieved 2026-10-24.

## What KnowMe Project Management does

- The work is packaged as one skill, `knowme-project-setup`, that follows the AgentSkills.io specification.
- The skill detects whether a project is new or existing and what type it is (code, business process, skill development, or research and docs), states its plan, and then runs its stages.
- A finished setup has one shared instruction file for every agent, a spec-driven change workflow (OpenSpec), tracked orchestration state, a knowledge log, an agent team with separate owned areas, product and design files, and a branded documentation site on GitHub Pages.
- The skill ships read-only detection and verification scripts, including a privacy check to run before any push.
- The README explains each setup step and lists the parameters that change from one project to the next.

Source: know-me-project-management README, retrieved 2026-10-24.
