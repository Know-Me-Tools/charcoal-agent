# 1.4 Integration gate: export omission line

Change `app-export-omission-note`, phase `site-chat-follow-ups`, date 2026-10-19. Base commit `7eb995d844efeb4face5dd745f61ca2c2e6daaa4` (origin/main 7eb995d plus the change's working tree at gate time).

## What was run

1. Production build, site flavour (same env as the Dockerfile build stage): `VITE_SITE_AGENT_ID=knowme-site VITE_SITE_WEB_SEARCH= VITE_UAR_API_KEY= VITE_UAR_BASE_URL= npm run build`.
2. The built bundle served by `vite preview`, Chromium via Playwright (temporary config, not committed), specs `e2e/chat-export-omission.spec.ts` and the existing privacy proof `e2e/chat-export.spec.ts`.
3. The Vite dev server (site flavour env), Chromium, `e2e/chat-export-omission.spec.ts`: this adds the stored chat with a form card and a remote image, which needs the dev server to write the thread into PGlite (the stream never produces image blocks).

Not covered: the remote image on the *built bundle*. The only way to put an image block in a chat is a stored thread, and writing one needs the dev server's module path. So the image case ran on the dev server only.
