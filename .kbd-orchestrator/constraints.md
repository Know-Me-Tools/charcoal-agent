# KBD Constraints — Charcoal Agent

Generated by `/kbd-init` on 2026-09-23. The project has no `AGENTS.md` "Never Do"
section, so the blocking rules below are the generic KBD defaults adapted to this
stack (Vite/React/TypeScript + Tauri shell) plus rules derived from `CLAUDE.md`.

Commands use `npm` (Dockerfile builds with `npm ci`; `package-lock.json` is the
authoritative lockfile). No mandatory command wrapper or `CARGO_TARGET_DIR` policy
is defined for this project.

Path ownership: `.claude/`, `.agents/`, `.opencode/`, `.kimi-code/` and `openspec/`
are repository-owned tool configuration (OpenSpec skills/commands), not disposable
state — do not delete or regenerate them as part of a change. Reference workspace
folders (see `project.json` → `workspace.folders`) are read-only.

## Blocking Constraints (prevent archiving until resolved)

```yaml
constraints:
  - id: build-passes
    severity: blocking
    description: 'Vite production build must pass'
    command: 'npm run build'

  - id: tests-pass
    severity: blocking
    description: 'Vitest suite must pass (skills-sync integration test self-skips without a UAR)'
    command: 'npm test'

  - id: no-console-log-in-commits
    severity: blocking
    description: 'No console.log in committed TypeScript (console.error/warn for real error paths is allowed)'
    check: "grep -rn 'console\\.log' src/ --include='*.ts' --include='*.tsx'"

  - id: no-any-type
    severity: blocking
    description: 'No new `: any` in TypeScript source (1 pre-existing occurrence at init; do not add more)'
    check: "grep -rn ': any' src/ --include='*.ts' --include='*.tsx'"

  - id: no-hardcoded-secrets
    severity: blocking
    description: 'No hardcoded API keys/tokens; UAR auth comes only from VITE_UAR_API_KEY'
    check: "grep -rn 'sk-[A-Za-z0-9]\\{8,\\}\\|Bearer [A-Za-z0-9]\\{16,\\}' src/"

  - id: no-env-files-committed
    severity: blocking
    description: '.env and .env.*.local must never be committed (only .env.example)'
    check: "git ls-files | grep -E '^\\.env($|\\.)' | grep -v '^\\.env\\.example$'"

  - id: reference-folders-read-only
    severity: blocking
    description: 'No writes to reference workspace folders (UAR, artifact-refiner, openfang)'
    note: 'Changes to the UAR contract are made in that repo separately, one PR per change in a separate worktree; this project only consumes it. prometheus-entity-management is not a reference folder: it is the operator''s own library and is writable by operator direction (D-30).'

  - id: pglite-migrations-append-only
    severity: blocking
    description: 'Existing entries in MIGRATIONS (src/lib/db/pglite.ts) must not be edited; add a new version instead'
    note: 'Review git diff of src/lib/db/pglite.ts'

  - id: pglite-not-prebundled
    severity: blocking
    description: '@electric-sql/pglite must remain in vite.config.ts optimizeDeps.exclude'
    check: "grep -q 'exclude: \\[\"@electric-sql/pglite\"\\]' vite.config.ts || echo MISSING"
```
